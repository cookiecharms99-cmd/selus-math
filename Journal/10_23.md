## 🍪 Scratchpad

- The original interface had `operator[]` only for a non-const `Vector`, which was a no-go.
- A `const` member function promises not to modify the object.
- The const overload should not hand out a mutable reference to its internal element, since that would provide a backdoor for modifying a const object.
- Returning a reference from `operator[]` gives access to the actual stored element instead of a copy.
- The const overload _could_ return a copy instead. A `const` reference preserves direct element access without allowing modification and generalizes better to expensive-to-copy element types.
- Constructor initializer lists such as `: elements(len)` construct members directly with the desired arguments rather than default-constructing them and assigning afterward.
